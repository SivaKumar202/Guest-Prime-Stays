# Guest Prime Stays — React + Vite + Tailwind CSS

## Phase 1
- Responsive navbar and mobile navigation
- Hero section
- Stay search form
- Brand highlights

## Phase 2
- Property collection and reusable property cards
- Category and guest-capacity filters
- Airbnb URL construction with dates and guest count

## Phase 3
- Our Story
- Guest Values
- Owner Services (revenue management and full-service co-hosting)
- Full-width editorial Image Break

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

The Phase 3 story and image-break image was extracted from the supplied source HTML and stored at `public/images/sections/atlanta-living-space.jpg`.

## Phase 4
- Hotel revenue management services for independent and boutique hotels
- Four hotel revenue service features
- Three-step owner/partner approach
- Reporting and transparency section using the original embedded suite photograph

The Phase 4 content and copy follow the supplied source HTML.

## Phase 5
- Five-question FAQ accordion using accessible native `details` / `summary`
- Final Atlanta stay call-to-action
- Owner inquiry form with property type, listing URL and service selection
- Form opens a prefilled email draft addressed to info@guestprimestays.com
- Responsive footer with contact details and section navigation

## Contact form behavior
The inquiry form uses a `mailto:` link, matching the supplied HTML behavior. It opens the visitor's configured email application; it does not submit to a backend or store inquiries.
